# UI.NT.Base/

Reserved pure classification folder (plain `.cs`, no csproj, no subfolders) for the `UI` static
partial class's NT-dependent addon functions at the library level, once any library-grade
content arrives here. Today's `UI.Fonts` zoom pattern lives only as a simplified illustration
under [`Samples/UI.NT.Base/`](../../Samples/README.md); this is where a full curation would land.

Every tier suffix, at any depth, is where the enums/classes supporting its sibling/optional
modules live (e.g. a future `UI.NT.Base.DEV/` would be an NT-dev-specific optional subset of
this folder's own content). Linked in by [`Source77NW.NT.Forms/`](../Source77NW.NT.Forms/README.md).
Full tier convention: [Source/README.md](../README.md).
